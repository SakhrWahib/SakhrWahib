## Featured project

### [Booking SaaS](https://github.com/SakhrWahib/booking-saas)

A multi-tenant booking platform for service businesses (salons, clinics, car wash, pet grooming, sports courts).

| | |
|---|---|
| **Multi-tenancy** | Tenant isolation on 13 tables through a global scope, tenant resolved by domain or subdomain, scoped validation rules |
| **SaaS platform** | Owner dashboard with MRR, plans, subscriptions, one-step tenant onboarding, and plan feature limits enforced by middleware |
| **Booking engine** | Slot capacity for individuals and teams, staff time off, double-booking prevention, calendar view |
| **Quality** | Feature tests for tenancy, availability, and admin pages; CI runs them on MySQL 8 for every push |
| **Stack** | Laravel 13 · PHP 8.3 · MySQL 8 · Sanctum · Tailwind · Vite · GitHub Actions · Dev Containers |
